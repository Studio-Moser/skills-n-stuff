# Interview question bank

Ask a question only when the project's documents and the references do not
already answer it. Each question lists when to skip it. Open questions are
asked in plain text and the answer is kept verbatim; choice questions offer the
listed options plus the owner's own.

## Project questions (only when there is no frozen brief)

These fill `templates/Frozen Brief.md`. Ask them once per project.

| # | Question | Kind | Skip when |
| --- | --- | --- | --- |
| P1 | What is this, who is it for, and what should a visitor do after reading it? | open | a strategy or positioning document says so |
| P2 | What is already fixed and not up for exploration: logo or marks, palette values, an existing typeface, a product name? | open | a brand guide exists; read it and confirm instead |
| P3 | Which three to five words should the identity carry, and which words would be wrong for it? | open | never; the owner's words are the content |
| P4 | What have you already seen and rejected for this? Name the lanes (for example "dark SaaS gradient", "editorial serif agency"). | open | never; this becomes the banned list |
| P5 | Which pages are in scope for exploration? | choice: homepage only / homepage plus one inner page / a named set | the owner already said |
| P6 | Where do the real facts live: client names, numbers, case studies, team? | open | found in the repository |
| P7 | Are there copy or voice rules, and where? | open | found in the repository |
| P8 | Is generated imagery allowed as a stand-in during exploration? | choice: yes, marked as stand-in / no, real assets only / no imagery at all | the frozen brief says |

## Stage 1: the seed

| # | Question | Kind | Skip when |
| --- | --- | --- | --- |
| S1 | In a sentence or two, what is the hunch? What do you want to see that you have not seen yet? | open | the owner opened with it |
| S2 | What should we call it? | open | the owner named it; otherwise propose three short names from the hunch |
| S3 | Where are you with this direction? | choice: wide (first look) / tightening (I have harvested a round) / prescriptive (converging) | it is the direction's first brief (wide) unless the owner says otherwise |
| S4 | Which pages does this round cover? | choice from the frozen brief's pages | one page is in scope |
| S5 | Does this use an existing copy direction, or does it need its own? | choice: list existing copy directions / new | the project has none (new) |

## Stage 2: references

Ask R1 once, then R2 to R4 per reference, after looking at it.

| # | Question | Kind | Skip when |
| --- | --- | --- | --- |
| R1 | Send me everything you are thinking of for this: links, screenshots, photos, files, things in the inspiration archive, or a description of something you cannot find. | open | never |
| R2 | What is it about this one? | open | the owner said so when sending it |
| R3 | I would borrow {the structural move} from it, and not {the thing that would make it a copy}. Right? | confirm or correct | never; this is the Reference pack row |
| R4 | Which part of it matters: the whole page, one section, the way it moves? | choice: whole page / a section (which) / the motion / the type / the colour | R2 already made it plain |
| R5 | These {n} are a lot to hand a builder. Which two to four lead? | choice | five or fewer |
| R6 | Is there anything these have in common that you have noticed? | open | the owner already connected them; otherwise ask once, before drafting the premise |

When a reference contradicts the frozen brief (a banned lane, a fixed palette
it ignores), say so and ask what survives: the move usually transfers without
the lane.

## Stage 3: the premise

| # | Question | Kind | Skip when |
| --- | --- | --- | --- |
| M1 | Here is the premise as I understand it: {draft}. What is wrong with it? | correct | never |
| M2 | The closest thing you have already rejected looks like {X}. This differs by {operation}. Is that the right line? | confirm or correct | the project has no rejected lanes and no siblings |
| M3 | Against {sibling}, this direction is the one that {does what}. Fair? | confirm or correct | no built siblings |

## Stage 4: the system

Draft first. These are the gaps a draft most often cannot close.

| # | Question | Kind | Skip when |
| --- | --- | --- | --- |
| Y1 | For type, I would shortlist {faces} because {reason}. Any face you already want, or cannot use? | confirm or correct | the frozen brief fixes the typeface |
| Y2 | Is a paid typeface licence available, or free and open faces only? | choice: paid is fine / open licence only / trial for exploration, licence on convergence | the project says |
| Y3 | How much should this direction move? | choice: still (type and layout carry it) / responsive (reveals, hover) / staged (scroll drives scenes) | the references are unambiguous |
| Y4 | What is the one thing this direction must never do? | open | the hard rules already drafted cover what the owner has said |
| Y5 | Anything a builder must keep on the page whatever the layout: a section, a logo wall, a form? | open | the frozen brief's funnel lines say |
| Y6 | Is there real imagery for this direction, or is it type-led? | choice: real assets (where) / stand-ins allowed / type-led | the frozen brief's imagery rule and the references settle it |

In the wide phase leave Page structure as a short list of what must appear and
say the order is the builder's call. In the prescriptive phase number every
section with its ground, what leads, and where the copy sits.

## Stage 5: wins and loses

| # | Question | Kind | Skip when |
| --- | --- | --- | --- |
| W1 | You would know a variant got this right if {drafted lines}. What would you add? | correct | never |
| W2 | And you would know it missed if {drafted lines}. Anything else that would make you close the tab? | correct | never |

Rewrite any line a stranger could not check from screenshots. "Feels
confident" is not checkable; "the headline is the largest thing on the first
screen at both widths" is.

## Stage 6: the copy direction

| # | Question | Kind | Skip when |
| --- | --- | --- | --- |
| C1 | What does this copy bet the reader needs to hear first? | open | reusing an existing copy direction |
| C2 | What does the first screen say, if you already know? | open | the owner has no line yet; draft three from the facts files and ask which is closest |
| C3 | Which proof is allowed to appear: which clients, numbers, quotes? | choice from the facts files | the facts files mark what is public |
| C4 | What should a visitor be asked to do, and in what words? | open | the frozen brief fixes the call to action |
| C5 | Any word or phrase this copy must never use? | open | the copy rules cover it |
| C6 | Here is the page, section by section. Mark any line that is not right. | correct | never; builders use these lines verbatim |
